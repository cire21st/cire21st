## Selected Work
### [ROS 2 Jazzy noVNC Docker](https://github.com/cire21st/ros-jazzy-novnc-docker)
A Docker-based ROS 2 Jazzy practice environment that can be accessed from a browser through noVNC.

- Built to reduce the setup barrier for ROS 2 practice
- Uses Ubuntu 24.04, Docker Compose, ROS 2 Jazzy, and noVNC
- Keeps workspace files persistent outside the container

### [Vision Macro](https://github.com/cire21st/vision_macro)
A small Python automation experiment that detects a target image on screen and clicks it.

- Uses PyAutoGUI image matching and OpenCV confidence thresholds
- Documents practical limitations such as DPI scaling and multi-monitor behavior
